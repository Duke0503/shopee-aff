# Project Context

Context holds discussion logs and decisions. It records what was discussed and decided, not what
the code does today. Once a decision is built, the docs in `docs/` describe the result.

- Discussions: [discussions/](./discussions/) (`domain/`, `design/`)
- Decisions: [decisions/](./decisions/). One file per approved decision, named
  `<date>-D<n>-<slug>.md`, mirrored in `docs/domain-model.json`
- PRDs, UX, architecture, epics and stories: [../_bmad-output/](../_bmad-output/)
